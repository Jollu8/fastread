# FastRead

FastRead — это лёгкое браузерное приложение для скорочтения текста и PDF-файлов. Оно показывает слова по одному, настраивает темп чтения и помогает читать в удобном ритме без установки тяжёлых программ.

## Возможности

- Чтение из `.txt`, `.md` / `.markdown` и `.pdf` файлов
- Markdown-разметка преобразуется в чистый текст; списки, подписи ссылок и блоки кода сохраняются
- Настройка скорости чтения (`WPM`)
- Варианты тем оформления: OLED, Midnight, Grey, Paper
- Звуковые подсказки на слово
- Фоновый эмбиент и визуальное фокусирование на слове
- Автосохранение прогресса и текста в браузере (`localStorage` и IndexedDB)
- Возможность продолжить чтение с того же места без повторного выбора файла

## Быстрый старт

Откройте опубликованную страницу GitHub Pages в браузере. Устанавливать или запускать сервер не нужно.

## Использование

1. Нажмите кнопку выбора файла.
2. Выберите `.txt`, `.md` / `.markdown` или `.pdf` документ.
3. Настройте скорость чтения, тему и звук.
4. Нажмите `Начать чтение`.
5. Во время чтения можно нажимать/тапать по экрану, чтобы управлять воспроизведением.

## Технологии

- HTML + CSS + Vanilla JavaScript
- Marked для разбора Markdown и PDF.js для чтения PDF-файлов (подключаются через CDN)
- Сборка и установка пакетов не требуются

## Публикация на GitHub Pages

Workflow `.github/workflows/pages.yml` автоматически публикует сайт при push в ветки `main` или `master`. Чтобы включить публикацию:

1. Откройте настройки репозитория на GitHub.
2. Перейдите в **Settings → Pages**.
3. В разделе **Build and deployment** выберите **GitHub Actions** в качестве источника.

После успешного запуска workflow сайт будет доступен по адресу `https://<ваш-пользователь>.github.io/<имя-репозитория>/`.

## Примечание

Это полностью клиентское статическое приложение: чтение и обработка файлов выполняются в браузере пользователя. Прогресс и кэш текста хранятся локально в браузере на этом устройстве и не синхронизируются между устройствами. GitHub Pages только раздаёт файлы сайта; серверная часть не требуется. Нужен современный браузер с поддержкой JavaScript и IndexedDB.
