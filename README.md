# FastRead

FastRead — браузерное приложение для RSVP-чтения: слова появляются по одному в одной точке экрана. Работает на GitHub Pages без серверной части и сборки.

## Чтение

- Интерфейс в стиле Apple с вкладками **Читать**, **Библиотека**, **Настройки**. Основные действия доступны без прокрутки; библиотека и длинные фрагменты разбиты на страницы.
- Скорость 100–1200 слов/мин, тёмная тема OLED по умолчанию, ещё три темы и дополнительное время на знаках препинания, заголовках и длинных фразах. Выбор темы сохраняется на устройстве и восстанавливается при следующем запуске.
- TXT, Markdown и PDF. Markdown разбирается по оформлению: без маркеров выделения и адресов ссылок, с целыми заголовками, подписями изображений и таблицами.
- Фразы в парных скобках и кавычках показываются вместе. Незакрытые скобки не захватывают остаток документа.
- Во время воспроизведения экран чтения скрывает шапку, прогресс и кнопки, оставляя слово и центральную метку; элементы управления возвращаются на паузе. Опорная красная буква располагается посередине слова, новое слово плавно проявляется без смещения. Анимация отключается при системной настройке «Уменьшение движения».
- На коде и таблицах чтение ждёт нажатия **Продолжить**. Для TXT распознаются блоки в обратных кавычках или тильдах; для Markdown — также строчный и отступный код.
- Из PDF извлекается текстовый слой с учётом расположения строк; похожие на код фрагменты определяются эвристически. Распознавание сканов (OCR) не поддерживается.
- Документы и место чтения автоматически сохраняются в локальной библиотеке.

## Звуковое сопровождение

Музыка сопровождает общий поток чтения. Отдельных звуков на каждое слово нет; время показа слов не зависит от музыкального BPM.

| Режим | Рекомендуемая скорость | Характер |
| --- | --- | --- |
| Focus | 150–299 слов/мин | Спокойная электронная атмосфера |
| Jazz Flow | 300–499 слов/мин | Ритмичный джаз, бас и ударные |
| Adrenaline | 300–499 слов/мин | Сердцебиение и напряжённый синтезаторный бас |
| Hyperflow | 500–799 слов/мин | Liquid Drum & Bass |
| Extreme | 800+ слов/мин | Плотный техно-ритм и глубокий бас |
| Silence | Любая | Без звукового сопровождения |

По умолчанию выбран Adrenaline: он включается с началом чтения без предварительного выбора, а его темп меняется вместе со скоростью чтения. На 300 слов/мин трек звучит с исходной скоростью; в диапазоне 100–1200 слов/мин скорость трека ограничена 0,8–1,75×. При ускорении повышается и тональность. Сохранённые настройки пользователя имеют приоритет.

Опцию **По скорости** можно включить отдельно: она предлагает Focus ниже 300 слов/мин, Jazz Flow при 300–499, Hyperflow при 500–799 и Extreme от 800. Adrenaline доступен как самостоятельный выбор. Любой режим можно выбрать при любой скорости. После ручного выбора изменение скорости не переключает музыку; автоматический подбор можно включить снова.

В настройках доступны громкость 0–100% и отключение звука; начальная громкость — 25%. Выбор режима, способ подбора, громкость и отключение звука сохраняются между сессиями.

Выбор режима и изменение громкости в настройках не запускают воспроизведение. Музыка запускается вместе с чтением, плавно затихает на паузе и продолжается с того же места при возобновлении. После завершения документа воспроизведение останавливается. При смене режима используется последовательное затухание и появление нового трека: одновременно несколько треков не играют. Аудио повторяется по кругу; плавность стыка зависит от исходной записи.

При открытии приложения и автоматическом подборе режима музыка не загружается. Ручной выбор заранее буферизует только выбранный трек; только при запуске чтения он воспроизводится по мере загрузки, без ожидания полного файла. Текст начинает показываться сразу, даже если музыка ещё загружается. Готовые данные повторно используются браузером при продолжении чтения; долговременное хранение музыки зависит от его кеша.

При отключённом звуке или нулевой громкости начало чтения не запускает загрузку музыки. Она подключается, когда пользователь включает звук.

Если браузеру нужно отдельное нажатие, используйте **Включить музыку** во время чтения. Ошибки загрузки и неподдерживаемого файла показываются отдельно от запрета воспроизведения. Если звук запрещён даже после нажатия, разрешите его для сайта в настройках браузера.

## Использование

1. На вкладке **Читать** откройте `.txt`, `.md` / `.markdown` или `.pdf`. Кнопка **Попробовать на примере** сразу запускает демонстрационное чтение.
2. Выберите скорость и музыкальное сопровождение. Для своего документа нажмите **Начать чтение**; ранее открытые документы доступны в **Библиотеке**.
3. Касание экрана переключает паузу. Свайп влево перемещает на 10 позиций вперёд, вправо — назад; те же действия доступны кнопками. Скорость меняется кнопками **− / +**.

С клавиатуры: **Пробел** — пауза, **← / →** — перемещение, **Escape** — выход. При уходе в другую вкладку браузера чтение и музыка останавливаются. Кнопка **×** в библиотеке удаляет документ; **Поддержать** ведёт в [Telegram автора](https://t.me/jollu8).

## Данные и работа без интернета

Документы хранятся в IndexedDB этого браузера; настройки и последняя позиция — также в localStorage. Содержимое файлов не отправляется на сервер. Старая библиотека сохраняется. При наличии исходного файла документ разбирается новым обработчиком, позиция переносится приблизительно по доле прочитанного. Ранее сохранённые пользовательские аудиофайлы не удаляются из хранилища при переходе на музыкальные режимы.

После первого успешного открытия и установки service worker приложение и библиотеки кешируются для работы без интернета. Музыкальные MP3 не входят в этот кеш: им требуется сеть или обычный кеш браузера. Удаление данных сайта очищает библиотеку, настройки и кеш; браузер также может освобождать локальное хранилище.

## Локальные аудиофайлы

Сопоставление режимов и файлов находится в `music-modes.js`. Для замены музыки измените `source` нужного режима на существующий файл проекта. Внешние музыкальные API не используются.

| Режим | Файл в `assets/sounds/` |
| --- | --- |
| Focus | `leberch-sci-fi-ambient-589945.mp3` |
| Jazz Flow | `icsilviu-rhythmic-jazz-289915.mp3` |
| Adrenaline | `tomas_herudek-heartbeat-and-tense-synth-529666.mp3` |
| Hyperflow | `audiodollar-liquid-drum-and-bass-477325.mp3` |
| Extreme | `alex-morgan-techno-warehouse-537487.mp3` |

Файлы предоставлены автором проекта из его локальной музыкальной библиотеки. У проектной копии трека Adrenaline удалён длинный тихий хвост: длительность сокращена с 34,656 до 32,160 секунды, в конце добавлено затухание 20 мс. Исходник в `Documents/sounds` сохранён. Остальные выбранные файлы скопированы без изменения; ранее добавленные треки также сохранены в проекте.

## Технологии и проверка

HTML, CSS и Vanilla JavaScript. Основные файлы: `app.js` — приложение и RSVP, `content-parser.js` — разбор текста, `music-modes.js` — каталог режимов, `music-player.js` — музыкальный проигрыватель. IndexedDB хранит библиотеку, localStorage — настройки, service worker — оболочку приложения. Marked 12.0.2 и PDF.js 2.16.105 с worker находятся в `assets/vendor/`; CDN не требуется.

Запустите статический сервер в каталоге проекта:

```sh
python3 -m http.server 4173
```

Откройте `http://localhost:4173`. Service worker работает на HTTPS и localhost; открытие `index.html` через `file://` не заменяет локальный сервер.

```sh
node --test tests/*.test.cjs
```

Дополнительно `tests/browser.cjs` и `tests/music-browser.cjs` проверяют браузерные сценарии в Chrome. Для них нужны запущенный локальный сервер и `playwright-core`; путь к модулю можно передать через `PLAYWRIGHT_MODULE`, к Chrome — через `CHROME_PATH`, адрес сайта — через `BASE_URL` (по умолчанию `http://127.0.0.1:4173`).

`tests/music-loading-browser.cjs` проверяет отсутствие MP3-запросов при открытии приложения и продолжение чтения при задержанной загрузке музыки.

## Публикация на GitHub Pages

Workflow `.github/workflows/pages.yml` публикует сайт при push в `main` или `master`. В настройках репозитория выберите **Settings → Pages → Build and deployment → GitHub Actions**.
